# Changelog

All notable changes to `pohunekd/plugin-antigravity` are recorded here.

## 0.1.0

- Initial release of the Antigravity CLI runtime plugin (`pohunek.runtime.agy`,
  runtime id `agy`), detection-only, verified against Antigravity CLI 1.5.16
  and 1.5.13 with OSC 7501 program-status and screen detection.
